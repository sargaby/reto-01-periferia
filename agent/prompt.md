# Comportamiento del agente — pendiente de implementación

Este documento reserva el system prompt exigido por el PRD. Todavía no se carga
desde el servidor ni existe un ciclo conversacional.

En la siguiente fase deberá definir: uso exclusivo de valores obtenidos por
herramientas, reporte de faltantes, trazabilidad y confirmación humana explícita
antes de cualquier envío simulado. El agente nunca firma ni envía al cliente.
